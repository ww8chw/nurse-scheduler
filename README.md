# 護理師月排班系統

A 7-day-a-week clinic nurse scheduling web tool with constraints, manual editing, image export, and Taiwan official 2025-2027 national holiday calendar.

## 🌐 線上使用

直接打開 [GitHub Pages 網址](https://ww8chw.github.io/nurse-scheduler/) 即可使用，無須安裝。

## ✨ 功能特色

- 🗓️ **自動計算當月應上工時**（依台灣勞基法：當月工作日 × 8 小時，扣除週休與國定假日）
- 👥 **5 位護理師排班**，可設定特定人不能排班的日期
- 🎲 **隨機演算法**：每次產生不同的最佳化結果（嘗試 3000 種組合）
- ⚖️ **多目標平衡**：工時、休假日、午晚診、醫美診、週六日班次平均
- 🌴 **連假最大化**：每人至少 1 次 3+ 天連休
- 📋 **連續上班 2-4 天 / 連休 2+ 天**規則
- ✏️ **手動修改**：點擊任一格子可改班別，工時即時更新
- ⏪⏩ **多版本歷史**：每次重新排班的結果都可前進/後退
- ↩️ **修改復原**：手動修改可一步步復原
- 📷 **PNG 圖片匯出**：可下載班表 PNG 檔
- 💰 **正/負時數結算**：依協議第 3.3 條，含「需補負時數」累計

## 🛡️ 班別代號

| 代號 | 班別 | 時段 | 工時 |
|---|---|---|---|
| A | 早診 | 08:00 – 12:00 | 4 hr |
| A+B+C | 早午晚診 | 08:00 – 21:00 | 10 hr |
| B+C | 午晚診 | 14:30 – 21:00 | 6 hr |
| 2F | 醫美診 | 12:00 – 21:00 | 9 hr |

## 📜 法律依據

工時計算依據：
- 勞動基準法
- 行政院人事行政總處 115 年（2026 年）辦公日曆表

## 🧑‍⚕️ Tech

純前端（HTML + CSS + JavaScript），無需後端，可離線使用。
- html2canvas（PNG 匯出）
- 自製啟發式排班演算法 + 隨機重啟
